30## Code
31
32Inline code: use `marko.parse(text)` to get the AST, then check
33`element.source_span`.
34
35```python
36import marko
37
38doc = marko.parse("# Hello")
39heading = doc.children[0]
40print(heading.source_span) # (0, 10)
41```
